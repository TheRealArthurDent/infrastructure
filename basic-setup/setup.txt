No need to change the Fritzbox DNS for a fresh install anymore: the base role makes the Pi fall back to the Fritzbox (192.168.1.1) for DNS
while its own Pi-hole is down or not installed yet (variable base_dns_fallback).


# Maybe somehow automate that down the road

1. Set vm overcommit_memory to 1 - needed for redis
    a >> create /etc/sysctl.d/90-overcommit-memory.conf with content:
        ###################################################################
        # Allow redis to use memory overcommit
        vm.overcommit_memory = 1
    b # Restart sysctl to apply
      systemctl restart systemd-sysctl

2. Install docker
~~~
(as root) curl -sSL https://get.docker.com | sh

sudo usermod -aG docker $USER
sudo reboot
~~~

3. Install rsnapshot and add config file to /etc/rsnapshot.conf

4. Make user smarthome a passwordless sudoer
    a >> copy /etc/sudoers.d/smarthome to raspi:/etc/sudoers.d/smarthome
    b >> chown root:root /etc/sudoers.d/smarthome
    c >> chmod 440 /etc/sudoers.d/smarthome

5. Restore from remote backup: see the "Restore" section in ansible/README.md
